Tikee — Selección de variables cuántico-inspirada para scoring crediticio

¿Formular la selección de variables como un problema QUBO mejora un modelo de scoring frente a LASSO o stepwise, cuando las variables candidatas están fuertemente correlacionadas? Se resuelve el mismo QUBO con cinco solucionadores distintos para separar el mérito de la formulación, del heurístico, y del paradigma de cómputo.

⚠️ Datos 100% sintéticos. Ninguna cifra de esta demo describe a ninguna cooperativa real. "Cuántico-inspirado" = recocido simulado clásico y un circuito QAOA simulado — no se usó hardware cuántico en ningún momento.

Resultado en una frase

En N=18 (Nivel A), la hipótesis no se sostiene con ganancia predictiva: QUBO empata en AUC con LASSO/stepwise, pero selecciona un subconjunto menos estable entre semillas — aunque más parsimonioso. En N=45 (Nivel B), la hipótesis se rechaza con significancia estadística: stepwise-AIC supera a QUBO, y el diagnóstico apunta a la formulación, no solo al heurístico.

    Figuras

    Detección de proxies (sesgo indirecto)

    Para cada brazo se entrena un clasificador auxiliar que intenta predecir el atributo protegido usando solo las variables que ese brazo seleccionó para el scoring. Un AUC alto significa que el subconjunto elegido codifica el atributo protegido aunque este nunca haya entrado al modelo de crédito. Lectura: ≈0.50 no hay proxy; >0.70 codificación sustancial.

    Para sexo y provincia ningún método muestra codificación sustancial. Para zona_residencia, usar todas las variables o LASSO permite reconstruirla casi perfectamente (AUC≈1.00); QUBO la reduce a 0.61 al usar ~40% menos variables. Ninguna diferencia de paridad demográfica superó 0.08 en los cinco brazos auditados.

    El argumento regulatorio (SEPS)

    Una cooperativa regulada por la SEPS debe poder sustentar la negación de un crédito. La selección vía QUBO es opaca en el procedimiento, pero el modelo resultante — una logística sobre 8-9 variables — es perfectamente interpretable y auditable. El intercambio real: en Nivel A, QUBO no gana AUC y pierde estabilidad de selección frente a LASSO/stepwise, pero reduce la codificación de zona_residencia y usa ~40% menos variables. Si el objetivo es minimizar sesgo indirecto medible y simplificar el expediente de crédito, QUBO tiene un argumento genuino. Si el objetivo es maximizar AUC con un método simple y estable, LASSO o stepwise son la elección correcta.

    Qué significa "cuántico-inspirado" aquí

    El recocido simulado (simulated annealing) es un heurístico clásico inspirado en un proceso físico, ejecutado en CPU normal — nunca en hardware cuántico. El brazo QAOA es un circuito cuántico simulado por software (vector de estado, Qiskit Aer), también sin hardware real. En N=18 el óptimo global ya se conoce por enumeración exhaustiva (2¹⁸=262.144 estados en segundos), así que QAOA no puede ganar — se incluyó para medir la brecha entre la promesa y la práctica, que resultó ser cero pero a un costo varios órdenes de magnitud mayor que la fuerza bruta. En N=45, QAOA ni siquiera puede ejecutarse: requeriría 563 TB de RAM para simular el circuito.

    Limitaciones declaradas

    • • Los datos son sintéticos; la estructura de correlación y el sesgo indirecto los impuso el equipo por diseño, para poder medir si los métodos de selección los recuperan.
    • • Tres desviaciones de parámetros respecto al diseño original quedaron documentadas en el código ([DESVIACIÓN DOCUMENTADA]), ninguna afecta los dos checkpoints innegociables.
    • • El límite de tiempo del MILP en el bucle de 10 semillas de Nivel B se redujo de 600s a 120s por presupuesto de tiempo; el hallazgo ("no cierra, se reporta el gap") es el mismo con ambos límites.
    • • La CV anidada de XGBoost se corrió sobre la semilla 42 únicamente, no sobre las 3 semillas especificadas en el diseño, por presupuesto de tiempo.
    • • La auditoría de equidad mide sobre sesgo que el equipo inyectó a propósito; detecta si un método propaga sesgo indirecto, no dice nada sobre el sesgo real del crédito en Ecuador.

    Anti-criterios respetados

    • ✓ Ningún hiperparámetro se ajustó después de ver métricas de test.
    • ✓ Se reportan las 10 semillas, nunca solo la mejor.
    • ✓ Relevancia y redundancia del QUBO se calcularon exclusivamente sobre el conjunto de entrenamiento.
    • ✓ El recocido nunca se presenta como "computación cuántica".
    • ✓ El brazo de óptimo certificado nunca se omitió, ni cuando no favoreció la hipótesis (Nivel B).
    • ✓ SDV se presenta como reproductor de una estructura impuesta por diseño, no como descubridor de correlaciones.
